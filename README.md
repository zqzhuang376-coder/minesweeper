# 方寸 · 经典扫雷

无需安装依赖的 HTML / CSS / JavaScript 小游戏。

## 本地运行

在项目目录执行 `npm start`，浏览器打开 `http://127.0.0.1:4173`。
也可以使用任意静态服务器托管 `dist/` 目录。由于使用 JavaScript 模块，请通过 HTTP 打开，而不是双击 HTML 文件。

## 玩法

- 初级：9 × 9，10 颗雷；中级：16 × 16，40 颗雷；高级：30 × 16，99 颗雷。
- 第一次翻开的格子及周围格子都安全，空白区域自动展开。
- 左键翻开，右键插旗。手机可以长按，或切换“插旗”模式。
- 数字周围旗子数量正确时，点击数字可快速翻开其余邻格；插错旗仍可能踩雷。
- 方向键移动，Enter / 空格使用当前模式，F 插旗。
- 翻开所有安全格即可获胜。难度、音效偏好与个人最佳保存在当前浏览器中。
- 高级棋盘可以横向滚动；所有难度均支持手机布局。

## 检查

运行 `npm test`。测试覆盖核心规则与交互边界。主逻辑位于 `dist/engine.js`，界面逻辑位于 `dist/app.js`。

在线字体不可用时自动使用系统字体，不影响游戏。
